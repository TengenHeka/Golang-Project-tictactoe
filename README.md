# Golang-Project
# 🎮 Tic-Tac-Toe CLI Game

A simple **Tic-Tac-Toe command-line game developed in Go (Golang)** as a project for **BCS Semester 2, NCMT College**.

## 👨‍💻 Team

* **Yunish Gurung**
* **Rustam Pandit**

## ✨ Features

* Two Player Mode
* Player vs Computer
* Win & Draw Detection
* Input Validation
* Score Tracking
* Replay Option

## 🛠️ Technologies

* Go (Golang)
* Git & GitHub

## ▶️ Run the Project

```bash
git clone https://github.com/TengenHeka/Golang-Project-tictactoe.git
cd Golang-Project-tictactoe
go run .
```
